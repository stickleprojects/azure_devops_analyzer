## Design Decisions

### 1. Mirror Team Metrics Pattern

**Decision**: Use [src/database/team_analytics.py](../../src/database/team_analytics.py) as the blueprint

**Rationale**:

- Proven pattern with 11 passing integration tests
- Similar aggregation problem (many contributors → team; many repos → service)
- Already uses the same underlying metrics tables
- Consistent API surface for consumers

**Pattern to follow**:

```python
def compute_service_metrics(session, service_id, period_start, period_end) -> ServiceMetric:
    """
    Aggregate metrics across all repositories belonging to a service.

    1. Get all repo_ids for the service (via repository_services junction)
    2. Aggregate contributor_metrics for those repos
    3. Aggregate quality_metrics, PR metrics, vulnerabilities
    4. Return ServiceMetric object (not yet persisted)
    """
```

### 2. Service Metrics Table Structure

**Decision**: Use TimescaleDB hypertable with 1-month chunks (same as team_metrics)

**Schema**:

```sql
CREATE TABLE service_metrics (
    id SERIAL,
    service_id INTEGER NOT NULL REFERENCES services(service_id) ON DELETE CASCADE,
    period_start TIMESTAMPTZ NOT NULL,
    period_end TIMESTAMPTZ NOT NULL,

    -- Repository counts
    total_repositories INTEGER DEFAULT 0,
    active_repositories INTEGER DEFAULT 0,  -- repos with commits in period

    -- Commit metrics (aggregated from contributor_metrics)
    total_commits INTEGER DEFAULT 0,
    total_lines_added INTEGER DEFAULT 0,
    total_lines_removed INTEGER DEFAULT 0,
    total_files_modified INTEGER DEFAULT 0,

    -- Pull request metrics
    total_prs_created INTEGER DEFAULT 0,
    total_prs_merged INTEGER DEFAULT 0,
    avg_pr_review_time_hours NUMERIC(10,2),

    -- Quality metrics (averaged across repos)
    avg_test_coverage NUMERIC(5,2),
    avg_maintainability_index NUMERIC(5,2),
    total_quality_issues INTEGER DEFAULT 0,

    -- Security metrics
    total_vulnerabilities INTEGER DEFAULT 0,
    critical_vulnerabilities INTEGER DEFAULT 0,
    high_vulnerabilities INTEGER DEFAULT 0,

    -- Dependency health
    total_dependencies INTEGER DEFAULT 0,
    eol_dependencies INTEGER DEFAULT 0,

    -- Activity metrics
    unique_contributors INTEGER DEFAULT 0,

    -- Audit
    computed_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,

    PRIMARY KEY (id, period_start)
);

SELECT create_hypertable('service_metrics', 'period_start',
    chunk_time_interval => INTERVAL '1 month'
);

CREATE INDEX idx_service_metrics_service_period
    ON service_metrics(service_id, period_start DESC);
```

### 3. Aggregation Functions

**Core Functions** (mirror team_analytics.py):

1. `compute_service_metrics(session, service_id, period_start, period_end)` → ServiceMetric
   - Main aggregation function
   - Returns object, doesn't persist (caller decides when to save)

2. `get_service_metrics(session, service_id, period_start=None, period_end=None)` → List[ServiceMetric]
   - Retrieve historical metrics
   - Supports time range filtering

3. `get_latest_service_metrics(session, service_id)` → Optional[ServiceMetric]
   - Get most recent computed metrics

4. `compute_all_services_metrics(session, period_start, period_end)` → List[ServiceMetric]
   - Batch compute for all services (useful for scheduled jobs)

```python
"""
Service-level analytics and metric aggregation.

Aggregates metrics across all repositories belonging to a service.
"""

import logging
from datetime import datetime
from typing import Optional

from sqlalchemy import func, select
from sqlalchemy.orm import Session

from src.database.models.service import Service, RepositoryService
from src.database.models.service_metric import ServiceMetric
from src.database.models.contributor_metrics import ContributorMetric
from src.database.models.quality_metrics import CodeQualityMetric
from src.database.models.pull_request import PullRequest
from src.database.models.dependency import Dependency

logger = logging.getLogger(__name__)


def compute_service_metrics(
    session: Session,
    service_id: int,
    period_start: datetime,
    period_end: datetime
) -> ServiceMetric:
    """
    Compute aggregated metrics for a service across all its repositories.

    Args:
        session: Database session
        service_id: Service to compute metrics for
        period_start: Start of time period (inclusive)
        period_end: End of time period (exclusive)

    Returns:
        ServiceMetric object (not yet persisted)

    Raises:
        ValueError: If service not found or no repositories linked
    """
    # Verify service exists
    service = session.get(Service, service_id)
    if not service:
        raise ValueError(f"Service {service_id} not found")

    # Get all repository IDs for this service
    repo_ids_query = select(RepositoryService.repo_id).where(
        RepositoryService.service_id == service_id
    )
    repo_ids = [row[0] for row in session.execute(repo_ids_query).fetchall()]

    if not repo_ids:
        logger.warning(f"Service {service_id} has no linked repositories")
        return _empty_service_metric(service_id, period_start, period_end)

    # Aggregate contributor metrics (commits, lines, files, PRs)
    contributor_agg = _aggregate_contributor_metrics(
        session, repo_ids, period_start, period_end
    )

    # Aggregate quality metrics
    quality_agg = _aggregate_quality_metrics(
        session, repo_ids, period_start, period_end
    )

    # Aggregate pull request metrics
    pr_agg = _aggregate_pr_metrics(
        session, repo_ids, period_start, period_end
    )

    # Aggregate security/dependency metrics
    security_agg = _aggregate_security_metrics(
        session, repo_ids, period_start, period_end
    )

    # Count unique contributors
    unique_contributors = _count_unique_contributors(
        session, repo_ids, period_start, period_end
    )

    # Count active repositories (repos with commits in period)
    active_repos = _count_active_repositories(
        session, repo_ids, period_start, period_end
    )

    # Build ServiceMetric object
    return ServiceMetric(
        service_id=service_id,
        period_start=period_start,
        period_end=period_end,
        total_repositories=len(repo_ids),
        active_repositories=active_repos,
        **contributor_agg,
        **quality_agg,
        **pr_agg,
        **security_agg,
        unique_contributors=unique_contributors,
        computed_at=datetime.utcnow()
    )


def _aggregate_contributor_metrics(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> dict:
    """Aggregate contributor metrics across repos."""
    result = session.execute(
        select(
            func.sum(ContributorMetric.commits).label("total_commits"),
            func.sum(ContributorMetric.lines_added).label("total_lines_added"),
            func.sum(ContributorMetric.lines_removed).label("total_lines_removed"),
            func.sum(ContributorMetric.files_modified).label("total_files_modified"),
            func.sum(ContributorMetric.prs_created).label("total_prs_created"),
        )
        .where(
            ContributorMetric.repo_id.in_(repo_ids),
            ContributorMetric.period_start >= period_start,
            ContributorMetric.period_start < period_end,
        )
    ).one()

    return {
        "total_commits": result.total_commits or 0,
        "total_lines_added": result.total_lines_added or 0,
        "total_lines_removed": result.total_lines_removed or 0,
        "total_files_modified": result.total_files_modified or 0,
        "total_prs_created": result.total_prs_created or 0,
    }


def _aggregate_quality_metrics(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> dict:
    """Aggregate quality metrics (averaged across repos)."""
    result = session.execute(
        select(
            func.avg(CodeQualityMetric.test_coverage).label("avg_test_coverage"),
            func.avg(CodeQualityMetric.maintainability_index).label("avg_maintainability"),
            func.sum(
                CodeQualityMetric.critical_issues +
                CodeQualityMetric.major_issues +
                CodeQualityMetric.minor_issues
            ).label("total_quality_issues"),
        )
        .where(
            CodeQualityMetric.repo_id.in_(repo_ids),
            CodeQualityMetric.recorded_at >= period_start,
            CodeQualityMetric.recorded_at < period_end,
        )
    ).one()

    return {
        "avg_test_coverage": result.avg_test_coverage,
        "avg_maintainability_index": result.avg_maintainability,
        "total_quality_issues": result.total_quality_issues or 0,
    }


def _aggregate_pr_metrics(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> dict:
    """Aggregate pull request metrics."""
    # Count merged PRs and avg review time
    merged_result = session.execute(
        select(
            func.count(PullRequest.pr_id).label("total_merged"),
            func.avg(
                func.extract('epoch', PullRequest.merged_at - PullRequest.created_at) / 3600
            ).label("avg_review_hours"),
        )
        .where(
            PullRequest.repo_id.in_(repo_ids),
            PullRequest.created_at >= period_start,
            PullRequest.created_at < period_end,
            PullRequest.merged_at.isnot(None),
        )
    ).one()

    return {
        "total_prs_merged": merged_result.total_merged or 0,
        "avg_pr_review_time_hours": merged_result.avg_review_hours,
    }


def _aggregate_security_metrics(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> dict:
    """Aggregate security and dependency metrics."""
    # Count vulnerabilities by severity
    vuln_result = session.execute(
        select(
            func.count(Dependency.dependency_id).label("total_vulnerabilities"),
            func.sum(
                func.case((Dependency.vulnerability_severity == "CRITICAL", 1), else_=0)
            ).label("critical_vulns"),
            func.sum(
                func.case((Dependency.vulnerability_severity == "HIGH", 1), else_=0)
            ).label("high_vulns"),
        )
        .where(
            Dependency.repo_id.in_(repo_ids),
            Dependency.has_vulnerabilities == True,
        )
    ).one()

    # Count total dependencies and EOL
    dep_result = session.execute(
        select(
            func.count(Dependency.dependency_id).label("total_deps"),
            func.sum(
                func.case((Dependency.is_eol == True, 1), else_=0)
            ).label("eol_deps"),
        )
        .where(Dependency.repo_id.in_(repo_ids))
    ).one()

    return {
        "total_vulnerabilities": vuln_result.total_vulnerabilities or 0,
        "critical_vulnerabilities": vuln_result.critical_vulns or 0,
        "high_vulnerabilities": vuln_result.high_vulns or 0,
        "total_dependencies": dep_result.total_deps or 0,
        "eol_dependencies": dep_result.eol_deps or 0,
    }


def _count_unique_contributors(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> int:
    """Count unique contributors across all service repos."""
    result = session.execute(
        select(func.count(func.distinct(ContributorMetric.contributor_id)))
        .where(
            ContributorMetric.repo_id.in_(repo_ids),
            ContributorMetric.period_start >= period_start,
            ContributorMetric.period_start < period_end,
        )
    ).scalar()

    return result or 0


def _count_active_repositories(
    session: Session,
    repo_ids: list[int],
    period_start: datetime,
    period_end: datetime
) -> int:
    """Count repos with at least one commit in the period."""
    result = session.execute(
        select(func.count(func.distinct(ContributorMetric.repo_id)))
        .where(
            ContributorMetric.repo_id.in_(repo_ids),
            ContributorMetric.period_start >= period_start,
            ContributorMetric.period_start < period_end,
            ContributorMetric.commits > 0,
        )
    ).scalar()

    return result or 0


def _empty_service_metric(
    service_id: int,
    period_start: datetime,
    period_end: datetime
) -> ServiceMetric:
    """Return empty metrics for service with no repos."""
    return ServiceMetric(
        service_id=service_id,
        period_start=period_start,
        period_end=period_end,
        total_repositories=0,
        active_repositories=0,
        computed_at=datetime.utcnow()
    )


def get_service_metrics(
    session: Session,
    service_id: int,
    period_start: Optional[datetime] = None,
    period_end: Optional[datetime] = None
) -> list[ServiceMetric]:
    """
    Retrieve service metrics for a time range.

    Args:
        session: Database session
        service_id: Service to retrieve metrics for
        period_start: Optional start filter
        period_end: Optional end filter

    Returns:
        List of ServiceMetric objects ordered by period_start DESC
    """
    query = select(ServiceMetric).where(ServiceMetric.service_id == service_id)

    if period_start:
        query = query.where(ServiceMetric.period_start >= period_start)
    if period_end:
        query = query.where(ServiceMetric.period_start < period_end)

    query = query.order_by(ServiceMetric.period_start.desc())

    return list(session.execute(query).scalars())


def get_latest_service_metrics(
    session: Session,
    service_id: int
) -> Optional[ServiceMetric]:
    """Get most recent computed metrics for a service."""
    result = session.execute(
        select(ServiceMetric)
        .where(ServiceMetric.service_id == service_id)
        .order_by(ServiceMetric.period_start.desc())
        .limit(1)
    ).scalar_one_or_none()

    return result


def compute_all_services_metrics(
    session: Session,
    period_start: datetime,
    period_end: datetime
) -> list[ServiceMetric]:
    """
    Compute metrics for all services (useful for scheduled jobs).

    Args:
        session: Database session
        period_start: Start of time period
        period_end: End of time period

    Returns:
        List of computed ServiceMetric objects (not persisted)
    """
    services = session.execute(select(Service)).scalars().all()

    metrics = []
    for service in services:
        try:
            metric = compute_service_metrics(
                session, service.service_id, period_start, period_end
            )
            metrics.append(metric)
        except Exception as e:
            logger.error(
                f"Failed to compute metrics for service {service.service_id}: {e}"
            )

    return metrics
```

**Example SQL queries**:

```sql
-- Total commits over time
SELECT
    period_start AS time,
    total_commits
FROM service_metrics
WHERE service_id = $service_id
  AND $__timeFilter(period_start)
ORDER BY period_start;

-- Repository breakdown
SELECT
    r.name as repository,
    SUM(cm.commits) as commits,
    SUM(cm.prs_created) as prs_created,
    AVG(qm.test_coverage) as avg_coverage
FROM repositories r
JOIN repository_services rs ON r.repo_id = rs.repo_id
LEFT JOIN contributor_metrics cm ON r.repo_id = cm.repo_id
LEFT JOIN code_quality_metrics qm ON r.repo_id = qm.repo_id
WHERE rs.service_id = $service_id
  AND cm.period_start >= NOW() - INTERVAL '30 days'
GROUP BY r.repo_id, r.name
ORDER BY commits DESC;
```

## Risk Mitigation

**Risk**: Query performance with large service portfolios (100+ repos)

**Mitigation**:

- TimescaleDB hypertable chunking (1-month intervals)
- Indexed on service_id + period_start
- Aggregation queries use indexed columns
- Test with realistic data volume before production

**Risk**: Missing data for new metrics

**Mitigation**:

- Handle NULL values gracefully (default to 0 or omit)
- Log warnings when underlying metrics missing
- Dashboard shows "N/A" for unavailable data

**Risk**: Dashboard query timeout

**Mitigation**:

- Use materialized views if queries too slow
- Add query timeout settings in Grafana
- Cache frequently accessed metrics
